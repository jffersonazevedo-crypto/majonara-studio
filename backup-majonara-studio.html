⬇️ Criar backup

Baixa uma cópia dos projetos, incluindo roteiros, cortes, textos e aprovações. Guarde o arquivo em um local seguro, como Arquivos ou iCloud Drive.

⬆️ Restaurar backup

Escolha um arquivo JSON exportado por esta ferramenta. Você poderá acrescentar projetos ao que já existe ou substituir a lista atual.

A opção “Adicionar” mantém os projetos atuais e ignora IDs duplicados. “Substituir” troca a lista inteira e só deve ser usada se você realmente quiser restaurar exatamente o conteúdo do arquivo.

⚠️ Importante

Esta ferramenta usa o mesmo armazenamento local do MAJONARA STUDIO neste endereço. Abra este arquivo pelo mesmo domínio do aplicativo e no Safari onde seus projetos estão salvos. Os dados do Chrome e do Safari são separados. Não limpe os dados do site antes de fazer um backup.
